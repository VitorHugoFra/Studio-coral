Visão técnica: de uma campanha a um pedido pago

Sequência das chamadas, com as rotas reais. As linhas tracejadas são respostas ou avisos que chegam depois.
sequenceDiagram
  autonumber
  participant AG as Agência / Restaurante
  participant PA as Painel (/app)
  participant SV as Servidor (Express + serviços)
  participant DB as PostgreSQL
  participant WA as WhatsApp (provedor)
  participant CL as Cliente final
  participant AS as Asaas

  AG->>PA: monta a campanha (mensagem, foto, cupom, filtros)
  PA->>SV: POST /api/campaigns
  AG->>PA: restaurante aprova
  PA->>SV: aprovação, depois "Enviar"
  SV->>DB: público = tags + filtros de compra
1 mensagem por contato, com código único
  loop DispatchService · horário comercial e limite diário
    SV->>WA: send() com nome, cupom e PUBLIC_URL/r/código
    WA->>CL: mensagem no WhatsApp
    WA-->>SV: /webhooks/whatsapp · enviada, entregue, lida
  end
  CL->>SV: GET /r/:código
  SV->>DB: registra o clique
  SV-->>CL: 302 para o site com sc_ref e UTM
  CL->>SV: POST /api/public/orders (itens, cupom, sc_ref, forma de pagamento)
  SV->>DB: cria ou atualiza o contato pelo telefone
grava o pedido atribuído à campanha
  alt Pix ou cartão
    SV->>AS: /customers, /payments, /pixQrCode
    SV-->>CL: resposta com o QR Code do Pix ou o link da fatura (cartão)
    CL->>AS: paga no app do banco ou na fatura do Asaas
    AS-->>SV: POST /webhooks/asaas/:restaurante (pago)
    Note over SV,AS: reserva: consulta a cada 15 s
sem pagamento no prazo, cancela e devolve o cupom
  else Paga na entrega
    Note over SV: segue direto
  end
  SV-->>PA: SSE "order": pedido entra no quadro
  AG->>PA: muda o status (em preparo, saiu, entregue)
  CL->>SV: GET /api/public/orders/:código (página de acompanhamento)
  opt Pedido veio de indicação
    SV->>WA: cupom de uso único para quem indicou
  end
  Note over SV,CL: se o cliente responde SAIR, o contato é descadastrado e não recebe mais mensagens
